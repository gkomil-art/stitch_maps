# Stitch Maps — универсальный сшиватель скриншотов карт

**Codex skill для сборки скриншотов Apple Maps, Google Maps, Яндекс Карт и других картографических источников в единый полноразмерный PNG.**

Доступны два режима: **сшивка готовых скриншотов** и **самостоятельная съёмка выбранной области карты с последующей сшивкой**. Обработка изображений общая; инструкции съёмки учитывают сервис, браузер и операционную систему.

## Возможности и статус проверки

| Сценарий | Статус |
|---|---|
| Сшивка готовых перекрывающихся изображений | Реализованы диагностика, начальное пакетное выравнивание, маски и сборка PNG; контрольные тесты выполнены на macOS |
| Apple Maps, приложение на macOS | Есть опыт реальной съёмки и сборки полной мозаики; завершающая очистка указателей в исходном сеансе осталась незавершённой |
| Google Maps / Яндекс Карты в браузере | Добавлены отдельные инструкции по официальной документации; сквозная живая проверка в этом сеансе не проводилась |
| Windows | Предусмотрены браузерные сценарии и переносимая обработка файлов; отдельная проверка на Windows-компьютере ещё требуется |

Для съёмки Codex необходим доступный инструмент управления приложением или браузером. Сам skill такого доступа не устанавливает. Для сшивки уже сохранённых файлов открывать карту и управлять компьютером не требуется.

## Режим 1. Самостоятельная съёмка карты

### Сначала сделайте общий скриншот

Откройте выбранный сервис и **сделайте один общий скриншот всей территории, которую хотите получить в большом разрешении**.

- Уменьшите масштаб так, чтобы вся нужная область помещалась в кадре.
- Используйте вид сверху без перспективного наклона, если задача не требует другого.
- Обозначьте границу, если нужна только часть видимой территории.
- Сохраните изображение, например как `Full_area.png`, и приложите его к запросу.

Если граница не нарисована, укажите, что нужно покрыть **весь прямоугольник обзорного изображения**, включая края. Обзор задаёт границы и ориентацию, а итог собирается из новых подробных кадров.

### Укажите местоположение и условия

Передайте:

1. Сервис: Apple Maps, Google Maps или Яндекс Карты.
2. Ссылку на локацию и название места.
3. Точные координаты WGS84, отдельно подписав **широту** и **долготу** в десятичных градусах.
4. Обзорное изображение и нужную границу.
5. Режим карты: спутник, гибрид или другой выбранный вид.
6. Требуемую линейку масштаба — по умолчанию **50 м**.
7. Допустимый способ совмещения: строго без изменения исходных пикселей либо с геометрическим выравниванием без уменьшения итогового разрешения.

Пример записи координат:

```text
Широта: 38.811155
Долгота: 65.774100
```

Используйте точку как десятичный разделитель; для южной широты и западной долготы — минус. Порядок координат внутри ссылок разных сервисов может отличаться, поэтому подписанные значения надёжнее неоднозначной пары чисел.

### Пример запроса на съёмку

```text
Используй $stitch-maps.

Режим: новая съёмка.
Система: <Windows или macOS>.
Сервис: <Apple Maps / Google Maps / Яндекс Карты>.
Локация: <название>.
Ссылка: <ссылка на выбранный сервис>.
Широта WGS84: <значение>.
Долгота WGS84: <значение>.
Обзор: Full_area.png, приложен к сообщению.

Покрой весь прямоугольник обзора, включая края.
Сними новые спутниковые кадры с видимой линейкой 50 м
и достаточным перекрытием. Ранее загруженные кадры не используй.

Разрешаю геометрическое выравнивание без уменьшения итогового
разрешения. Собери один PNG, проверь покрытие и швы,
исключи указатели и элементы интерфейса. Сохрани исходники отдельно.
Если ровно 50 м недоступны, сначала согласуй другой масштаб.
```

При живой съёмке оставляйте сеанс компьютера доступным и разблокированным. После блокировки потребуется ручная разблокировка и проверка текущего положения карты; сохранённые кадры можно использовать для продолжения.

## Режим 2. Сшивка готовых скриншотов

Приложите исходные изображения или укажите доступную папку. Желательно сообщить сервис, порядок кадров, направление рядов, масштаб и ориентацию. Соседние кадры должны иметь общие детали; обычно удобно перекрытие 25–35% по обеим осям.

Координаты и обзор полезны для определения границ, но не обязательны, если нужно собрать все предоставленные кадры и область понятна. Если на исходниках нет линейки, skill не будет заявлять, что метрический масштаб проверен. Изображения разных сервисов или дат съёмки по умолчанию собираются отдельно.

```text
Используй $stitch-maps.
Собери приложенные скриншоты Google Maps в один полноразмерный PNG.
Кадры сняты рядами слева направо, затем следующий ряд справа налево.
Разрешаю геометрическое выравнивание без уменьшения итогового разрешения.
Проверь пропуски, швы и отсутствие указателей. Сохрани исходники отдельно.
```

Для строгого сохранения исходных пикселей замените разрешение на выравнивание строкой:

```text
Допускаются только целочисленные сдвиги и обрезка.
Если точная сшивка так невозможна, покажи проблему и согласуй изменение режима.
```

## Что необходимо

- Codex с установленным skill `stitch-maps`.
- Исходные скриншоты **или** исходные данные и доступ к управлению картой для новой съёмки.
- Интернет и доступность выбранного сервиса — только для живой съёмки.
- Записываемая рабочая папка и свободное место для снимков, временных данных и PNG. Большая область может потребовать несколько гигабайт временного пространства.
- Для Python-инструментов обработки: NumPy, Pillow и OpenCV с поддержкой SIFT.

Установка зависимостей в выбранное Python-окружение:

```bash
python -m pip install -r requirements.txt
```

Используйте доступную команду своего интерпретатора: например, `python3` на macOS или `py` на Windows. Инструменты не требуют ключей картографических API для работы с готовыми изображениями.

## Установка skill

Поместите содержимое репозитория в пользовательский каталог skills Codex, в папку **`stitch-maps`**. При стандартной конфигурации:

- macOS: `~/.codex/skills/stitch-maps`;
- Windows: `%USERPROFILE%\.codex\skills\stitch-maps`.

Если задан собственный `CODEX_HOME`, используйте его подкаталог `skills/stitch-maps`. Для новой установки, когда целевая папка ещё не существует:

macOS:

```bash
git clone https://github.com/gkomil-art/stitch_maps.git ~/.codex/skills/stitch-maps
```

Windows, PowerShell:

```powershell
git clone https://github.com/gkomil-art/stitch_maps.git "$env:USERPROFILE\.codex\skills\stitch-maps"
```

При обновлении сохраните свои изменения. Вызов skill: `$stitch-maps`.

## Как проверяется результат

Skill проверяет реальную геометрию совпадающих объектов, перекрытия, связность серии и полноту покрытия. Надпись «50 м» — это отметка видимой линейки, а не 50 метров на пиксель; одинаковая надпись на двух снимках не гарантирует одинакового размера объектов в пикселях.

Геометрическое выравнивание может менять положение, поворот, масштаб и перспективу отдельных кадров. Оно отличается от уменьшения итогового разрешения и применяется с учётом условий запроса. Проверяются швы на разметке, дорогах, крышах и других деталях. Недостающие или закрытые указателем участки требуют дополнительных реальных кадров; детали не дорисовываются.

Результат — полноразмерный PNG, сохранённые исходники и отчёт проверки. Уменьшенное превью, если нужно, выдаётся отдельно. Геопривязка и экспорт в GeoTIFF требуют отдельной задачи.

## Инструменты и устройство

- `SKILL.md` — основной процесс и выбор режима.
- `references/providers.md` — Apple Maps, Google Maps и Яндекс Карты.
- `references/platforms.md` — особенности macOS/Windows и статус проверки.
- `references/capture-and-resume.md` — съёмка и продолжение работы.
- `references/alignment-and-quality.md` — выравнивание и контроль качества.
- `references/processing-tools.md` — команды и форматы данных.
- `scripts/mosaic_tools.py` — диагностика пары, начальное пакетное выравнивание и сборка PNG с масками.
- `scripts/test_mosaic_tools.py` — автономные контрольные тесты обработки.

Для готовых изображений инструмент `align` рассчитывает начальные положения и проверяет связность и ошибки замыкания. Сложной серии может понадобиться дополнительное глобальное выравнивание. Границы результата проверяются перед сборкой; рендерер отклоняет PNG с непокрытыми пикселями.

Проверка локальных инструментов:

```bash
python scripts/test_mosaic_tools.py
```

Это skill для Codex с инструментами обработки, а не самостоятельный загрузчик карт. Он не обходит ограничения сервисов и не устанавливает средства управления компьютером.

Инструкции провайдеров опираются на официальную справку [Google Maps](https://support.google.com/maps/answer/3092439?co=GENIE.Platform%3DDesktop&hl=en) и [Яндекс Карт](https://yandex.com/support/maps/en/concept/map-control); фактический интерфейс проверяется перед съёмкой.
